how to emulate gcam with ambrosia

We have tested whether running ambrosia will produce the same output as gcam when both are run with the same parameters, prices, income, and bias adders. We find generally yes, although the match isn't as good for Qs as I thought it would be, and that in the Ref_HD run, GCAM produces 20+ results with NAs for demand.
 
Next, we want to test whether running ambrosia with alternative parameters (such as HD), relative to a reference case (such as Ref_ML), would produce the same output as GCAM with those same alternative parameters. In this test, the ambrosia scenario should be calculated with no information from the new GCAM run.

So we first generate the GCAM scenario. It should have the same income as the reference case, but use the HD parameters instead of ML. It would calculate new bias adders consistent with the demand generated by the HD parameters. It would solve for prices and demand endogenously.

Next we generate the ambrosia scenario. It should have the same income as the reference case, but use HD parameters instead of ML. It should use the prices from the reference case, because it would not know the new prices that GCAM might produce for the alternative scenario. It also would not know the new bias adders that GCAM would solve for. So, it should calculate its own new bias adders, such that demand in the base year with the new HD parameters is equal to demand with the reference (ML) parameters (since by definition those should be equal to observations). This can be done by calculating demand in the base year with HD parameters and zero bias, and subtracting it from base year demand in the reference case, for each region. In principle this should yield the same result as the GCAM bias adders. These regional bias terms should then be used in all years in the full calculation of ambrosia demand. 

However in practice this does result in some differences in regional demand in the base year. The reason is that regional demand is calculated as the average per capita consumption across the 10 deciles. In some cases, the regional bias adder in the HD case will push demand below zero for one or more deciles, when in the reference scenario, demand is positive. Thus in the HD case demand in those deciles will be adjusted to zero, an adjustment that is not made in the reference case. Therefore the bias adder does not result in an equal change in per capita consumption in all deciles, and therefore the change to regional demand is not equal to the bias adder either, and regional demand will not be the same in the reference case and the HD case.

bias adders              HD                       Calculated (should be same as GCAM HD)
